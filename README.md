# 油站设备巡检清单

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 设备复检与班组交接闭环

- **异常生成复检**：异常巡检可生成复检任务，记录责任班组、时段与复查人，结果必须绑定原记录。
- **规则引擎**：
  - 规则1 设备时段唯一：同一设备同一时段只能有一个进行中的复检；
  - 规则2 班组容量：同一班组同一时段进行中复检不超过 3 项，任务重叠不得超载；
  - 规则3 待处理保护：复检完成前原异常保持待处理，禁止流转或重复发起；
  - 规则4 绑定保护：存在绑定复检的原记录不得删除；
  - 规则5 留痕调整：复检通过后不得直接改写，调整必须填写原因并保留旧版；
  - 规则6 交接规则：跨班交接先释放原班组，未完成复检转入下一班。
- **冲突面板**：触发规则时列出设备、时段、班组与触发规则；班组负载看板实时展示各时段占用。
- **一致性**：localStorage 持久化，刷新后自动校验绑定关系、修复丢失引用，并重放规则扫描存量冲突。
